# Error log

The most valuable file here. Every wrong answer goes in, same day, no
exceptions. Patterns show up within two weeks and they are almost never
what you'd have guessed.

Error types: `knowledge` (didn't know it) · `method` (knew it, chose a slow
or wrong route) · `slip` (arithmetic/algebra) · `misread` (answered a
different question) · `time` (would have got it with more time)
